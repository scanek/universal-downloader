# 🎬 Универсальный медиа-загрузчик (Universal Downloader)

[![Docker](https://img.shields.io/badge/Docker-Ready-2496ED?logo=docker&logoColor=white)](https://www.docker.com/)
[![Python](https://img.shields.io/badge/Python-3.12-3776AB?logo=python&logoColor=white)](https://www.python.org/)
[![yt-dlp](https://img.shields.io/badge/yt--dlp-Latest-red?logo=youtube&logoColor=white)](https://github.com/yt-dlp/yt-dlp)
[![PWA](https://img.shields.io/badge/PWA-Mobile_Ready-5A0FC8?logo=pwa&logoColor=white)](https://web.dev/progressive-web-apps/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Автономный домашний медиа-сервер для скачивания видео, аудио, плейлистов и треков с **YouTube, VK, Rutube, TikTok, SoundCloud, Дзена, Одноклассников и ещё 1000+ поддерживаемых сайтов**.

Проект полностью оптимизирован для работы в **Docker на домашнем NAS (Synology, TrueNAS, Unraid, QNAP, Linux-сервер)** и повседневного использования всей семьёй с любых компьютеров, планшетов и смартфонов.

---

## 💡 Что было переработано и сделано в этой версии

Проект вырос из локального скрипта в полноценный автономный веб-сервис для домашнего сервера с глубокой интеграцией в инфраструктуру:

1. **🐳 Чистая контейнеризация под домашний сервер (Docker & Docker Compose):**
   * Образ на базе лёгкого `python:3.12-slim-bookworm` со встроенными **FFmpeg** и **Deno** (для расшифровки сигнатур YouTube).
   * Удалены все лишние привязки к локальному десктопу Windows (`.bat`, `.vbs`, `pystray`).
   * Внедрён механизм **`gosu` с переменными `PUID` и `PGID`**: контейнер запускается от root для настройки окружения, но процесс и сохранение файлов идут строго от ID вашего пользователя системы (например, `1000:100`). В результате у скачанных файлов в сетевой папке (`/volume2/shara/Downloads`) **нет проблем с правами доступа (Permission Denied)** — их можно сразу открывать, переименовывать и удалять через SMB/Windows Explorer/Plex.

2. **🛡 Встроенная работа через Tinyproxy / VPN (обход блокировок и замедлений):**
   * Загрузчик умеет направлять свой трафик через локальный HTTP-прокси (например, связка **AmneziaWG / WireGuard + Tinyproxy** на сервере).
   * **Пользователям дома не нужно включать VPN на смартфонах или ПК** — скачивание роликов с YouTube происходит напрямую через серверный VPN-туннель.
   * В интерфейсе есть переключатель прокси с живой проверкой соединения и отображением внешнего IP-адреса.

3. **📱 Мобильное приложение PWA и системная кнопка «Поделиться» (Web Share Target API):**
   * Поддержка стандартов **Progressive Web App (PWA)**: адаптивные иконки, манифест и Service Worker.
   * На Android и iPhone сервис устанавливается как отдельное приложение в 1 клик.
   * **Интеграция с системным меню смартфона:** при просмотре ролика в официальном приложении YouTube, VK или Telegram нажимаем **«Поделиться» ➡️ «Скачиватель»** — ссылка автоматически передаётся в сервис и сразу начинает анализироваться!

4. **🍪 Управление `cookies.txt` прямо из браузера (18+ и закрытые видео):**
   * Больше не нужно подключаться по SSH или лезть в файловую систему NAS, чтобы загрузить куки для YouTube.
   * В интерфейсе реализован файловый селектор и **Drag & Drop**: просто перетащите файл `cookies.txt` в окно браузера.
   * Сервер валидирует формат Netscape, извлекает список поддерживаемых сайтов, отображает статус подключения (🟢 размер, домены) и позволяет удалить cookies в один клик.

5. **🌐 Поддержка Reverse Proxy и Authentik (`ProxyFix`):**
   * Внедрён middleware Werkzeug `ProxyFix` с поддержкой доверенных прокси-сетей Docker (`172.16.0.0/12`, `10.0.0.0/8`, `192.168.0.0/16`).
   * Корректно определяются реальные IP клиентов, схемы `https` и заголовки `X-Forwarded-Host`/`X-Forwarded-Proto`. Сервис работает без сбоев за **Nginx Proxy Manager**, **Traefik**, **Caddy** и шлюзом авторизации **Authentik**.

6. **📁 Встроенный Web-файловый менеджер хранилища:**
   * Просмотр файлов на диске сервера прямо в веб-интерфейсе.
   * Индикатор свободного места на накопителе NAS.
   * Быстрый поиск по медиатеке.
   * Прямое скачивание любого готового файла на телефон или ПК.
   * Полноценный стриминг видео и аудио (поддержка `Range: bytes` для плавной перемотки в браузере).
   * Кнопка быстрого копирования сетевого пути SMB (`\\192.168.1.2\shara\Downloads`).

7. **🔄 Автоматическое самообновление `yt-dlp`:**
   * Фоновый планировщик раз в сутки проверяет и обновляет движок `yt-dlp`.
   * При обновлении контейнер автоматически безопасно перезапускается через exit-код `42`, поэтому алгоритмы скачивания всегда остаются актуальными.

8. **🧩 Браузерное расширение v2.0 (Manifest V3):**
   * Готовое расширение для Chrome, Edge, Яндекс.Браузера и Firefox.
   * Сервер генерирует преднастроенный архив по адресу `/extension.zip` — в него уже «вшит» адрес вашего сервера.
   * Скачивание по клику на иконку в панели или через контекстное меню правой кнопки мыши.

9. **🎯 Выбор целевого устройства на лету:**
   * **«📱 На телефон / ПК»**: браузер сразу сохраняет файл на устройство, с которого вы открыли страницу.
   * **«🖥 На сервер (NAS)»**: файл отправляется в постоянную сетевую папку на накопителе сервера.

## 🚀 Быстрый запуск в Docker Compose

### 1. Клонирование репозитория
```bash
git clone https://github.com/scanek/universal-downloader.git /volume1/docker/universal-downloader
cd /volume1/docker/universal-downloader
```

### 2. Настройка `docker-compose.yml`
Отредактируйте пути к хранилищу и ID вашего пользователя:

```yaml
services:
  universal-downloader:
    build: .
    image: universal-downloader:latest
    container_name: universal-downloader
    restart: unless-stopped
    ports:
      - "8765:8765"
    environment:
      - PUID=1000                 # ID вашего пользователя в Linux (id -u)
      - PGID=100                  # ID вашей группы (id -g, на Synology часто 100 users)
      - HOST=0.0.0.0
      - PORT=8765
      - DOWNLOAD_DIR=/downloads
      - CONFIG_DIR=/config
    volumes:
      # Папка для сохранения скачанных файлов (укажите вашу общую папку на NAS):
      - /volume2/shara/Downloads:/downloads
      # Папка для сохранения конфигурации и cookies.txt:
      - ./config:/config
```

### 3. Запуск
```bash
docker compose build
docker compose up -d
```

Сервис готов к работе по адресу: **`http://<IP_СЕРВЕРА>:8765`** (например, `http://192.168.1.2:8765`).

## 🔒 Настройка за Reverse Proxy (NPM Plus / Authentik / Traefik)

Если вы публикуете сервис наружу через домен с SSL (HTTPS):

1. **Nginx Proxy Manager:**
   * **Forward Hostname / IP:** имя контейнера или IP NAS (например, `192.168.1.2`).
   * **Forward Port:** `8765`.
   * Включите **Websockets Support** и **Block Common Exploits**.
   * Во вкладке **SSL** выберите сертификат Let's Encrypt и включите **Force SSL**.
2. **Authentik:**
   * Благодаря встроенному `ProxyFix` авторизация через Authentik Forward Auth / Proxy Provider работает прозрачно. Редиректы возвращают пользователя строго на внешний HTTPS-домен.

## 📱 Как установить на телефон (PWA)

1. Откройте веб-интерфейс в мобильном браузере через ваш HTTPS-домен.
2. **Android (Chrome):**
   * Нажмите кнопку **«📱 Установить PWA»** в шапке сайта (или в меню браузера **⋮** ➡️ *«Установить приложение»*).
3. **iPhone / iPad (Safari):**
   * В Safari нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх) ➡️ выберите **«На экран «Домой»** (➕).
4. **Использование:**
   * В приложении YouTube, VK или Rutube нажмите кнопку **«Поделиться»** ➡️ выберите **«Скачиватель»**. Ссылка сразу откроется в приложении!

## 🍪 Авторизация для закрытых и 18+ видео

1. Установите в настольный браузер расширение для экспорта куков (например, [Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)).
2. Откройте YouTube (или нужный сайт), экспортируйте файл `cookies.txt`.
3. В веб-интерфейсе скачивателя просто перетащите файл `cookies.txt` мышкой в окно браузера (или нажмите кнопку **«Загрузить cookies.txt»**).
4. Загрузчик мгновенно активирует куки и покажет статус `🟢 Подключен`.

---

## 🧩 Установка расширения для браузера на ПК

1. В веб-интерфейсе разверните блок **«Скачивать прямо с сайта»** и нажмите **«Скачать расширение (zip)»** (или скачайте по адресу `http://<IP_СЕРВЕРА>:8765/extension.zip`).
2. Распакуйте архив в постоянную папку.
3. В браузере (Chrome / Edge / Яндекс):
   * Перейдите в `chrome://extensions` (или `edge://extensions`).
   * Включите **«Режим разработчика»** в правом верхнем углу.
   * Нажмите **«Загрузить распакованное расширение»** и укажите распакованную папку.
4. Теперь скачивать видео можно в 1 клик по кнопке на панели или через правый клик мыши по любой ссылке/видео.

## 📂 Структура репозитория

```text
universal-downloader/
├── app.py                 # Основной Flask-бэкенд: API, ProxyFix, стриминг, PWA Share Target, cookies
├── sites.py               # Кастомные экстракторы для нестандартных ресурсов
├── Dockerfile             # Сборка контейнера с Python 3.12, FFmpeg, Deno и gosu
├── docker-compose.yml     # Готовый файл развёртывания с переменными PUID/PGID
├── entrypoint.sh          # Скрипт инициализации окружения, прав и авто-рестарта при обновлении
├── requirements.txt       # Оптимизированный список Python-библиотек
├── .dockerignore          # Исключение лишних файлов из сборки Docker
├── extension/             # Исходный код браузерного расширения Manifest V3
│   ├── manifest.json      # Манифест расширения
│   ├── background.js      # Фоновый сервис-воркер и меню правой кнопки
│   ├── popup.html/js/css  # Всплывающее окно управления и статуса
│   └── config.js          # Адрес сервера (подставляется динамически при отдаче zip)
└── web/                   # Фронтенд (Single Page Application)
    ├── index.html         # Главный интерфейс, аудиоплеер, File Manager, PWA диалог
    ├── help.html          # Справочная страница и диагностика
    ├── sw.js              # Service Worker для работы PWA
    ├── manifest.json      # Манифест PWA-приложения
    └── icons/             # Иконки высокого разрешения для PWA (192px, 512px)
```
